# 🏗️ Painel de Obras Estruturantes do Ceará

> Painel interativo de acompanhamento das principais obras de infraestrutura do estado do Ceará, mantido pela **AJE Fortaleza** (Associação de Jovens Empresários de Fortaleza).

## 📋 Sobre

Este painel reúne informações atualizadas de **21 obras estruturantes** distribuídas em **8 eixos estratégicos**:

| Eixo | Exemplos |
|------|----------|
| 🚇 Mobilidade | Linha Leste do Metrô, VLT Aeroporto |
| 🚂 Ferrovia | Transnordestina |
| 💧 Hídrica | Cinturão das Águas, Eixão das Águas |
| 🛣️ Rodovias | BR-222, BR-116, BR-020 |
| ⚡ Energia | Hidrogênio Verde, Data Center ZPE |
| 🚰 Saneamento | PPP 127 cidades, Esgoto RMF |
| 🏥 Saúde | Hospitais Regionais |
| 🏖️ Turismo | Saneamento de Preá |

## ✨ Funcionalidades

- 📊 **KPIs resumidos** — visão geral de investimentos e progresso
- 🔍 **Busca e filtros** — por eixo ou texto livre
- 📈 **Progresso visual** — anéis e barras de execução física
- 📰 **Últimas notícias** — com fontes oficiais
- 🏷️ **Badges de atualização** — obras recém-atualizadas em destaque
- 📱 **Design responsivo** — funciona em desktop e mobile

## 🚀 Como Rodar

### Pré-requisitos

- [Node.js](https://nodejs.org/) 18+ 
- npm 9+

### Instalação

```bash
# Clone o repositório
git clone https://github.com/tiagoggl12/painel-obras-ce.git
cd painel-obras-ce

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

O app estará disponível em `http://localhost:5173`.

### Build para Produção

```bash
npm run build
npm run preview
```

## 🤝 Como Contribuir

Contribuições são muito bem-vindas! Veja como participar:

1. **Fork** este repositório
2. Crie uma branch para sua feature: `git checkout -b feature/minha-feature`
3. Commit suas alterações: `git commit -m 'feat: adiciona nova funcionalidade'`
4. Push para a branch: `git push origin feature/minha-feature`
5. Abra um **Pull Request**

- 📝 Atualização de dados das obras
- 🐛 Correção de bugs
- ✨ Novas funcionalidades
- 🎨 Melhorias de design
